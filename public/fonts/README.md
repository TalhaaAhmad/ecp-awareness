# Preview typography

The website self-hosts DejaVu Sans to match the fallback typeface rendered in the supplied design-pack PNG previews. No font service is contacted at build time or at runtime.

Fonts: DejaVu Sans Book and Bold, distributed with Matplotlib v3.10.7:
- https://github.com/matplotlib/matplotlib/tree/v3.10.7/lib/matplotlib/mpl-data/fonts/ttf
- Original project: https://dejavu-fonts.github.io/
